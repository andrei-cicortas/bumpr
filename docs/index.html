How it works

  1. Bump the pin in an isolated virtualenv and run the tests.
  2. Read the docs: Tavily finds the official migration guide; Nemotron Nano reads the whole page and hands over only the relevant passages, verbatim, each checked against the source.
  3. Think & rewrite: Nemotron Ultra plans every change and rewrites the files.
  4. Prove it: tests run again; failures go back to Ultra until everything is green.
  5. Ship: Nano writes the pull request; you get the patch.

When a software library gets a big update, apps break.
Bumpr repairs them automatically, and proves the repair works.

Think of a car. The manufacturer redesigns a part, and your car no longer starts. A mechanic would read the new manual, change what's needed, and test-drive the car. Bumpr does the same for software: it reads the library's new official manual, rewrites the code with NVIDIA's Nemotron AI, and "test-drives" it with automatic checks until every check passes again.

Words you will see, explained
Library
Ready-made code that many apps reuse. pandas works with tables of data, a bit like Excel inside a program.
Upgrade
Moving to a new edition of a library (pandas 2 → pandas 3). Big editions rename or remove things, which breaks apps.
Tests (checks)
Small automatic checks that the app still gives the right answers, e.g. "revenue for March is 180". Green = passed, red = failed.
Documentation (docs)
The library's official manual, published on its website.
Nemotron Ultra / Nano
NVIDIA's AI models. Ultra is the big one that thinks and writes code; Nano is a small, cheap one that reads the manual.
Tavily
A search engine built for AI: it finds and fetches the right documentation page.
Diff
A before/after view of code: red lines were removed, green lines were added.

    Run Bumpr yourself

    This hosted page replays real, unedited runs. Live runs need your own Nebius Token Factory and Tavily keys (Tavily's free tier is enough):

    git clone https://github.com/andrei-cicortas/bumpr
cd bumpr
pip install -r requirements.txt
cp .env.example .env   # add NEBIUS_API_KEY, TAVILY_API_KEY

# web UI with live runs
uvicorn web.server:app --port 8000

# or the CLI, on any repo with pytest + requirements.txt
python -m bumpr samples/pandas-sales-report pandas --to 3
