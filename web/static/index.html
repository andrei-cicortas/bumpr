How it works

  1. Bump the pin in an isolated virtualenv and run the tests.
  2. Read the docs: Tavily finds the official migration guide; Nemotron Nano reads the whole page and hands over only the relevant passages, verbatim, each checked against the source.
  3. Think & rewrite: Nemotron Ultra plans every change and rewrites the files.
  4. Prove it: tests run again; failures go back to Ultra until everything is green.
  5. Ship: Nano writes the pull request; you get the patch.
